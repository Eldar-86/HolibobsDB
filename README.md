# HolibobsDB

By Eldar Klimentić

## Description

HolibobsDB is a relational database built with SQLite for a holiday rental platform. It supports the core data requirements for managing property listings, owners, renters, availability, pricing, bookings, and payments.

## Features

 * Relational database design using primary and foreign keys
 * Data integrity enforced through SQL constraints
 * Triggers for booking history, payment events, and availability updates
 * Views for querying related data
 * Indexes to support common queries

## Technologies

 * SQL
 * SQLite
